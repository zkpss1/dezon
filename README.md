# Dezon Móveis Planejados

Site institucional em React, Vite e Tailwind, com portfólio de projetos reais.

## Rodar localmente

```sh
npm ci
npm run dev
```

Abra `http://localhost:3000`.

## Verificar e gerar a versão de publicação

```sh
npm run lint
npm run build
```

Os arquivos prontos para hospedagem ficam em `dist/`. As páginas internas usam rotas com `#`.

Antes de publicar, confirme com a Dezon os dados de contato, horários e regiões atendidas exibidos no site.
